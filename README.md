# Tag Ziguprisma

Tag Ziguprisma é um jogo feito para rodar como um webapp totalmente local para dois jogadores
O título do jogo é a união da palavra Tag – palavra em inglês utilizada para denominar a brincadeira do “pega-pega”, da palavra “Zigurate” 
O projeto é baseado num prisma oco de nove faces. O sistema de captura é inspirado no xadrez, onde há a necessidade de ambos jogadores ocuparem a mesma casa para haver um vencedor.  

## 🚀 Como Baixar o Projeto (Arquivo ZIP)

Se você não tem o Git instalado ou prefere não usar a linha de comando, pode baixar todo o código deste projeto diretamente em um arquivo compactado `.zip`.

Siga o passo a passo abaixo:

1. Vá até o topo desta página do repositório no GitHub.
2. Clique no botão verde escrito **Code** (localizado no lado direito, acima da lista de arquivos).
3. No menu que aparecer, clique em **Download ZIP**.
4. Salve o arquivo no seu computador.
5. Extraia (descompacte) o arquivo ZIP na pasta de sua preferência.

---

## 🎮 Próximos Passos (Como Jogar)

Após descompactar o arquivo, siga estas etapas para rodar o projeto localmente:

1. Abra a pasta extraída e clique duas vezes no arquivo Index.html.(alternativamente você pode arrastar o arquivo para a barra de pesquisa do seu navegador)
2. Comece a jogar(Use as setas do teclado)
